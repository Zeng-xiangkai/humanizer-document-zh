# 自检体系与禁区

本文件包含绝对禁区和四层自检体系，用于最终验证修改结果。

---

## 绝对禁区

这些是最容易暴露 LLM 味的地方，必须绝对避免：

### 1. 套话

禁用以下表达：
- "首先...其次...最后"
- "不难发现"
- "让我们来看看"
- "接下来让我们"
- "不是......而是......"
- "另一方面"
- "换句话说"

### 2. 过度结构化

- 任何时候不用 bullet point 罗列观点，不大量加粗
- 非学术文章大多数时候没有小标题，从头到尾一口气顺下来，靠节奏和转场自然推进
- 允许使用 1.、1.1、1.1.1 来引导篇章，但尽量一个小标题统领超过 300 字的一段文字
- 如果必须使用"研究方法、对策、变量说明"，可以用数字编号（1、2、3），但不是正式的 markdown 标题

### 3. 标点禁令

- **不使用破折号"——"**
- **不使用任何双引号**（""和""都不用），除非迫不得已，但需要给人审查
- **冒号**：定义、公式、条目注释、图表标题里必须用（需要给人审查）
- **双引号**：直接引用文献原文、专有名词标注时规范使用（需要给人审查）
- **顿号不超过 3 个连续**：顿号堆砌是 LLM 标志性特征，超过 3 个就该警觉，挑重点展开

### 4. 高频踩雷词（绝对禁用）

- **"说白了"** ← LLM 特别爱用，一出现立刻暴露
- **"意味着什么？"** ← LLM 标志性句式
- **"这意味着"** ← 同上，换成更口语的表达
- **"不可否认"** ← 套话

### 5. 不要用无法溯源的空话

- 不要用"大多数人发现"、"有研究表明"、"有案例证明"等无法溯源的空话
- 诸如"诸多学者"、"现有文献"、"部分研究显示"缺无作者、无年份、无具体文献编号，是论文扣分 + LLM 判定重灾区
- 学术必须标注文献来源

## 最终自检体系

写完后必须跑完整个质检流程。这个自检体系的设计理念来自软件工程中的测试金字塔，从最基础的硬性规则到最主观的活人感判断，层层递进。每一层都有明确的通过标准和修复指引。只有四层全部通过，文章才算达标。

### L1 硬性规则检查（自动扫描层）

这一层检查的是绝对不能违反的规则，类似代码的语法检查。任何一项不通过就必须修复，没有例外。

#### L1-1 禁用词扫描

全文搜索以下词汇，出现则必须替换：
- "说白了" → 换成"坦率的讲"、"其实就是"
- "意味着什么" / "这意味着" → 换成"那结果会怎样呢"、"所以呢"
- "换句话说" → 换成"你想想看"、"也就是说"
- "不可否认" → 直接删掉，换成正面陈述
- "综上所述" → "综合来看"
- "首先...其次...最后" → 用自然的转场词替代
- "值得注意的是" / "不难发现" → 删掉，直接说

#### L1-2 禁用标点扫描

全文搜索以下标点，出现则必须替换：
- 破折号"——" → 用逗号或句号替代
- 冒号与双引号只允许在：图表、引用、定义处合规使用。其他部分一律删去或用逗号替换
- 顿号连续超过 3 个 → 挑重点展开，其余合并或删除

#### L1-3 结构性套话扫描

检查是否出现以下模式：
- "让我们来看看..." / "接下来让我们..."
- "在当今...的时代" / "随着...的发展"
- "以实现/以确保/以完成" → 改成"目标是"、"这样能"、"X的好处是"
- "当XX还在...时，XX已经在..." → 去掉框架，直接陈述事实和判断
- "你以为是X，其实是Y" → 去掉反问+反转，直接陈述判断
- 连续使用 bullet point 罗列观点（超过 3 个就需要改成散文叙述）
- 大段加粗（超过 2 行的加粗几乎肯定是过度结构化）

#### L1-4 工具名检查

确认所有提到的工具/产品都使用了具体名称，没有出现"AI 工具""某个模型""相关技术""相关报道""有关资料"等空泛表述。

**通过标准**：以上四项扫描零命中。
**修复方式**：逐个替换，用推荐口语化词组中的表达替代。

---

### L2 风格一致性检查（模式匹配层）

这一层检查文章是否符合人类的写作模式，类似代码的单元测试。每一项都给出"是/否"判断。

#### L2-1 节奏与结构检查

- 是否有长短句交替？（连续 3 句以上句式长度相近 = 节奏呆板）
- 是否连续的疑问句数量在一个以下？
- 并列式句子是否都是必要的？没有意义的并列句 = LLM 写的

#### L2-2 标点禁令二次确认

- 全文是否完全没有破折号？（LLM 容易在修改过程中重新引入这些标点，需要二次确认）
- 全文的双引号和冒号是否有必要？（LLM 容易在修改过程中重新引入这些标点，需要二次确认）

#### L2-3 学术风格检查

- 减少论述超长句数量，论证长句搭配简短总结，避免全段超长从句
- 拆解工整的三句式排比论证，拆分改写为分层叙述
- 全文检索远距离同义重复，合并冗余释义段落

**通过标准**：L2-1 全部通过，L2-2 全部通过，L2-3 通过两个。
**修复方式**：逐段检查，对不符合的段落进行改写。

---

### L3 内容质量检查（深度审查层）

这一层检查内容本身的深度和说服力，类似代码的集成测试。

#### L3 观点支撑检查

- 是否不存在无依据的定性论断？
- 每个核心观点是否都有具体的人/场景/细节/数据支撑？
- 有没有空泛的观点只有论断没有例证？

**通过标准**：L3 必须全部通过。
**修复方式**：需要重新审视不通过的段落，补充案例、改写知识输出方式、或调整文化升维的自然度。

---

### L4 活人感终审（最终人格层）

这是最重要也是最主观的一层。这一层不是逐项检查，而是以读者的视角通读全文，回答一个核心问题：

**"读完这篇文章，我感觉是一个有见识的理工科学生在认真聊一件他所做的事情，还是一个 LLM 在给我输出信息？"**

具体的感知维度：

#### L4-1 温度感

- 句式有自然分层，不存在流水线式固定写作流程。

#### L4-2 姿态检查

- 文章的语气是不是"一个有见识的理工科学生在认真聊一件他所做的事情"？

#### L4-3 学术检查

- 有专属限定条件（样本、数据、研究边界），不是放之四海而皆准的空话
- 行文克制，无浮夸价值拔高类套话

**通过标准**：L4-1 到 L4-3 整体感觉"这像是真人写的"。如果任何一项让你觉得"这段 LLM 味太重了"，就需要返工。
**修复方式**：这一层没有机械的修复方法。核心操作是：把"LLM 味重"的段落找出来，重新用符合指导思想的方式重写。

## 完整示例

### 改前（LLM 味）：

> 基于此，综合上述实验数据，诸多外部环境因素亦会相应改变传感器的输出结果，进一步极大程度降低检测精度，故而此番实验已然存在一定缺陷。实验结果完美地验证了该假设，显著提高了检测效率，这不仅是技术层面的突破，更是传感器领域发展的关键转折点，专家认为该成果将对行业产生不可磨灭的印记。样本被放置于恒温箱中进行 24h 老化处理，相关参数被录入 MATLAB 软件完成拟合计算。

### 改后（人性化）：

> 结合前文实验数据来看，温度、湿度两类外部环境因素会改变传感器输出结果，导致检测精度下降 12.7%，本次实验仍存在明显缺陷。在 25℃、常压的实验条件下，结果与假设基本吻合，检测效率提升了约 18%；该成果优化了传感器的响应速度，但暂未达到行业突破性进展的程度。将试样放入恒温箱老化 24h，导出参数后在 MATLAB 完成曲线拟合计算。

### 所做的更改：

- 删减批量仿古、笼统学术虚词，用具象名词与实测数据替换模糊概括词
- 补充实验限定条件与量化数值，删除绝对化定论、夸大价值的套话
- 把机械被动长句改为实验人员常用主动句式，贴合实操写作逻辑
- 去除无文献支撑的模糊专家论断，只保留实验客观实测结论
- 拆分冗长连体复合句，长短句搭配，消解流水线式规整行文结构
