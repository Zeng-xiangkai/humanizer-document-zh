# Humanizer Document ZH

去除中文学术写作中的 AI 味，让论文/报告读起来更像人写的。

## 这是什么

一个 Claude Code Skill，用于识别并移除 LLM 生成文本的典型痕迹。基于知乎高赞回答（最高 757 赞）、Wikipedia "Signs of AI writing" 等来源，总结了 **28 种常见 AI 写作模式**，配合四层自检体系，系统性地去除"AI 味"。

## 适用场景

- 中文论文、毕业论文、期刊投稿
- 学术报告、研究报告
- 任何需要"去 AI 味"的中文写作

**触发词：** "去 AI 味"、"人味儿"、"AI 感太重"、"论文润色"、"学术写作优化"

## 核心内容

### 28 种 AI 写作模式

按优先级分为三层：

| 优先级 | 模式 | 说明 |
|--------|------|------|
| 🔴 第一优先 | 破折号滥用、顿号堆砌、"以"字句、修辞过度等 | 最容易暴露 AI 味 |
| 🟡 第二优先 | 万能动词、虚词滥用、对比句式、翻译腔等 | 内容与句式问题 |
| 🟢 第三优先 | 宏观强调、因果绝对化、填充短语等 | 其他模式 |

每种模式包含：
- 识别方法（高频词汇/句式）
- 问题描述
- 改前/改后对比示例

### 四层自检体系

借鉴软件工程的测试金字塔设计：

1. **L1 硬性规则检查** — 禁用词、禁用标点、套话扫描
2. **L2 风格一致性检查** — 节奏、标点、学术风格
3. **L3 内容质量检查** — 观点支撑、论据充分性
4. **L4 活人感终审** — 最终判断"读起来是否像真人写的"

## 安装

将整个 `humanizer-document-zh` 文件夹放到 Claude Code 的 skills 目录：

```bash
cp -r humanizer-document-zh ~/.claude/skills/
```

## 使用

在 Claude Code 中，当你的文本需要去 AI 味时，直接说：

```
帮我把这段论文去去 AI 味
```

```
这段话太像 AI 写的了，帮我改改
```

```
润色一下我的毕业论文，去掉 AI 感
```

Skill 会自动触发，按照优先级扫描 28 种模式，重写有问题的部分，并输出：
1. 重写后的文本
2. 所做更改的简要总结
3. 需要补充的内容和不确定的地方

## 完整示例

### 示例 1：传感器实验报告

**改前（AI 味）：**
> 基于此，综合上述实验数据，诸多外部环境因素亦会相应改变传感器的输出结果，进一步极大程度降低检测精度，故而此番实验已然存在一定缺陷。实验结果完美地验证了该假设，显著提高了检测效率，这不仅是技术层面的突破，更是传感器领域发展的关键转折点，专家认为该成果将对行业产生不可磨灭的印记。

**改后（人性化）：**
> 结合前文实验数据来看，温度、湿度两类外部环境因素会改变传感器输出结果，导致检测精度下降 12.7%，本次实验仍存在明显缺陷。在 25℃、常压的实验条件下，结果与假设基本吻合，检测效率提升了约 18%；该成果优化了传感器的响应速度，但暂未达到行业突破性进展的程度。

### 示例 2：《三体》读书报告

**改前（AI 味）：**
> 《三体》是刘慈欣创作的长篇科幻三部曲，作为中国科幻文学的里程碑之作，该书不仅凭借恢弘磅礴的宇宙架构、天马行空的科学想象打破了大众对国产科幻的认知，更跳出了单纯的科技叙事，以星际文明博弈为载体，深度剖析人性、反思文明、叩问人类生存的终极意义。

**改后（人性化）：**
> 《三体》是刘慈欣写的长篇科幻三部曲。这部作品在国内科幻圈的地位不用多说，但让我真正读进去的，不是它有多宏大的宇宙设定，而是它把人性摊开来给你看的方式。三部曲读下来，最让我反复琢磨的，是那些在绝境里做选择的人。
